# Product Requirements Document (PRD)

## Project Name
Perry

## Project Overview
Perry is a personal goal and task tracker web application designed with an exceptionally modern, beautiful UI/UX. The app aims to be fully responsive, catering to users on mobile, tablet, and desktop devices.

## Key Features
1. **Goal and Task Management**  
   - Users can add tasks with a description, due date, and priority weight (low, medium, high).
   - Ability to delete, edit, and view tasks.
   - Support for themes in goals (e.g., Spiritual, Physical Fitness, Academics, Career).
   - Users can create and manage their own categories for both tasks and goals.

2. **Calendar View**  
   - Tasks are visualized by date in a calendar layout.
   - Clicking on a day with tasks expands or zooms into that day, allowing interaction with all tasks and activities scheduled.

3. **Progress Dashboards**  
   - Provide visual progress tracking through charts for today, this week, this month, and this year.
   - Use percentages or a hybrid metric to display progress.

## UI/UX Design Requirements
- **Overall Style**:  
   - Modern, minimal, and highly polished appearance.
   - Default dark theme with soft accent colors for a calm user experience.

- **Responsive Design**:  
   - Ensure compatibility across mobile, tablet, and desktop devices.
   - Calendar-first layout with smooth expand/zoom interactions for daily tasks.

- **Task Cards and Animations**:  
   - Clean, easy-to-read task cards with subtle animations.
   - Simple progress charts displaying day/week/month/year metrics.

## Target Audience
- The application is for personal use only; therefore, no authentication is required.

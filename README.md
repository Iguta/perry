# Perry

Perry is a personal goal and task tracker web application with an exceptionally modern, minimal, and polished UI. It is designed to be fully responsive across mobile, tablet, and desktop.

## Features
- Goal and task management with description, due date, and priority (low/medium/high)
- Create, edit, delete, and view tasks
- Themed goals (e.g., Spiritual, Physical Fitness, Academics, Career)
- Custom categories for both tasks and goals
- Calendar view with day expand/zoom to interact with tasks
- Progress dashboards for today, this week, this month, and this year

## UI/UX
- Default dark theme with soft accents
- Calendar-first layout with smooth interactions
- Clean task cards and subtle animations

## Tech Stack
- React + TypeScript (Vite)
- CSS (component-scoped styles)

## Scripts
From `perry/codebase`:
- `npm install`
- `npm run dev`
- `npm run build`
- `npm test`
